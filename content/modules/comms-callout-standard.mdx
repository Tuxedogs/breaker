steps:
  - label: Use the fixed order
    detail: Contact or target first, then range or aspect, then action or need.
  - label: Keep the call actionable
    detail: Short beats perfect. Do not bury urgent traffic under commentary.
  - label: Repeat only what matters
    detail: Critical state changes can be repeated once if they are not acknowledged.
  - label: Use explicit handoff language
    detail: Passing a task from pilot to gunner or engineer should never be implied.
  - label: Close the loop
    detail: Acknowledge critical calls like repair state, tackle state, or disengage state.
failureModes:
  - Mixed order forces repeated clarification
  - Extra detail blocks urgent traffic
  - Critical handoffs are implied but never acknowledged

Consistency matters more than perfect phrasing. Use the same structure every time.
