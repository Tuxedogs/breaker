Shield regeneration is not consistent across faces. Pilots should note that the front face regenerates fastest under default power distribution because it receives priority allocation in the stock power curve.

Engineers can shift regeneration priority by redistributing power mid-fight. Calling power mode changes on comms is essential — a blind shift can starve the face currently taking fire and cause a cascade collapse.

Numbers below reflect 3.24 patch data. Verify against current erkul values before a planned engagement.
