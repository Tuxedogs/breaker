## Vehicles - Target Cycling
| Keybind Description | Default Key | Effect |
| --- | --- | --- |
| Cycle Lock Sub-Target-Forward | `R` | Rotates through components starting at crosshair |

## What does it do? 
 - Sub-targeting changes where and how you apply your damage, mechanically and systematically via in-game assists. 
 - Targeted components will become the focus point for Fixed Assist and ESP, allowing significantly higher hit rates.
 - Understanding its functionality and when to use it is required for Ares/Howler crews.

>Sub-targeting can only be achieved in precision mode, once acquired freedom return to normal view is often preferred.
## When To Cycle through Sub-Targets

- Before the merge, on approach. Nav mode does not interfere with precision and sub target cycling.
- The crew can maintain a stable enough angle to keep the selected component in view.
- You can confirm the selected subsystem in precision mode or via MFD.

## General Targeting Logic

- Aim near the intended subsystem before cycling.
- Confirm the highlight and use the Cycle Sub-Target-Forward keybind.
- Reset the lock if the game state becomes ambiguous instead of guessing.
- Remember that missiles and torpedoes follow the same intent logic: a good sub-target selection changes the strike result.
